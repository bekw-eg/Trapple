# Trapple music: Jingles

Статус: WAV ещё не созданы. Эта папка подготовлена для проверенных мастеров.

| Будущий файл | Композиция | Целевая длительность | Промпт |
| --- | --- | ---: | --- |
| Level_Complete.wav | Level Complete | 4.000 s | [12_level_complete](../../../../Docs/Audio/Prompts/12_level_complete.txt) |
| Victory.wav | Victory | 6.500 s | [13_victory](../../../../Docs/Audio/Prompts/13_victory.txt) |
| Game_Over.wav | Game Over | 4.000 s | [14_game_over](../../../../Docs/Audio/Prompts/14_game_over.txt) |
| Boss_Defeated.wav | Boss Defeated | 8.000 s | [15_boss_defeated](../../../../Docs/Audio/Prompts/15_boss_defeated.txt) |
| Upgrade_Purchased.wav | Upgrade Purchased | 1.500 s | [16_upgrade_purchased](../../../../Docs/Audio/Prompts/16_upgrade_purchased.txt) |

Формат цели: WAV, 48 kHz, 24-bit integer PCM, stereo. Никаких вокала, речи
или voice samples. Не добавлять пустые WAV вместо отсутствующего аудио.

Фоновые треки зацикливаются целиком; джинглы проигрываются один раз и
включают естественное затухание. Для босса Magma обе фазы должны иметь
одинаковую длину и музыкальную сетку.
