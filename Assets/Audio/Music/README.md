# Trapple — музыкальные ресурсы

Статус: структура папок подготовлена; аудиофайлы пока не созданы.

[Полный пакет производства](../../../Docs/Audio/README.md) содержит
16 готовых промптов, семинотный мотив Appi, каталог и план интеграции.

В каждую папку помещать только проверенные WAV-мастера с именами из каталога.
Unity должен создать AudioImporter .meta при реальном импорте каждого WAV;
сохранить этот .meta вместе с аудио. Текущие .meta относятся только к папкам
и README. Музыка автоматически не запускается: MusicManager пока описан
как предложение в документации.
