# Trapple music: Workshop

Статус: WAV ещё не созданы. Эта папка подготовлена для проверенных мастеров.

| Будущий файл | Композиция | Целевая длительность | Промпт |
| --- | --- | ---: | --- |
| Appis_Workshop.wav | Appi's Workshop | 115.200 s | [03_workshop](../../../../Docs/Audio/Prompts/03_workshop.txt) |

Формат цели: WAV, 48 kHz, 24-bit integer PCM, stereo. Никаких вокала, речи
или voice samples. Не добавлять пустые WAV вместо отсутствующего аудио.

Фоновые треки зацикливаются целиком; джинглы проигрываются один раз и
включают естественное затухание. Для босса Magma обе фазы должны иметь
одинаковую длину и музыкальную сетку.
