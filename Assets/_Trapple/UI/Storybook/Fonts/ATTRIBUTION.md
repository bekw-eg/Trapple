# Thaleah

Unmodified original **ThaleahFat.ttf**, by Rick Hoppmann / Tiny Worlds.
Downloaded from the author's distribution:
https://tinyworlds.itch.io/free-pixel-font-thaleah

The author distributes it under CC BY 4.0:
https://creativecommons.org/licenses/by/4.0/

Unity Asset Store listing: https://assetstore.unity.com/packages/2d/fonts/free-pixel-font-thaleah-140059

The generated TMP SDF atlas uses a crisp brown outline. No substitute font or
Cyrillic fallback is installed in the new UI. English captions match the supplied
artwork; the original configuration strings and save data remain untouched.
