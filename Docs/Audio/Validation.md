# Проверка пакета саундтрека

Дата: 26 октября 2026 года.
Ветка: feature/soundtrack-production-kit.
База PR: origin/main, 0ec7fe6.

## Поставлено

- 16 отдельных самодостаточных промптов: 11 фоновых версий, 5 джинглов.
- Единый семинотный мотив Appi, варианты по мирам и MIDI-эталон.
- Каталог целевых темпов, длительностей, имён WAV и границ полных циклов.
- Девять папок назначения внутри Assets/Audio/Music с README и .meta.
- Инструкции для производства, приёмки и интеграции MusicManager.

Полный перечень файлов: [ChangedFiles.md](ChangedFiles.md).

## Выполненные проверки

Статическая проверка данных стандартным Python:

- Все 16 ID и целевых путей уникальны, каждый ссылается на отдельный промпт.
- Все заданные BPM и длительности попадают в диапазоны пользовательского ТЗ.
- Число кадров фоновых треков рассчитано из темпа, тактов и 48 kHz;
  у джинглов — из полной длительности с хвостом.
- Обе фазы Magma имеют одинаковые BPM, длину, тональность и число кадров;
  промпты задают одинаковую гармоническую сетку и позиции фраз.
- Каждый промпт короче 5000 символов и содержит требования к формату,
  инструментальности и завершению/зацикливанию.
- MIDI разобран по событиям: format 0, один track, 480 PPQ, 120 BPM, 4/4,
  ровно семь ожидаемых note-on/note-off; 3840 ticks, то есть 4 секунды.
- Все внутренние Markdown-ссылки разрешаются.
- Для каждой новой папки и README в Assets есть .meta; GUID уникальны
  относительно всех существующих Assets/*.meta, осиротевших новых .meta нет.
- UTF-8 читается, служебные placeholders отсутствуют.
- git diff --check проходит; добавлены только Docs/Audio и Assets/Audio.
  Runtime, сцены, префабы и ProjectSettings не изменены.

Это проверка производственного пакета, а не музыкального качества.
Временные проверочные команды не добавляют проекту новый test framework.

## Что не выполнено и почему

Runway подключён и доступность проверена. Попытка создания Main Theme
отклонена до создания задачи: account_limitation / paid_plan_required.
Поэтому аудио не получено, и ни одной композиции не присвоен статус готовой.
TrackCatalog.status = prompt_package_no_rendered_audio, все треки —
awaiting_generation.

Не выполнены прослушивание, анализ WAV/клиппинга/true peak/LUFS,
проверка отсутствия голосов, оригинальности мелодий и бесшовности циклов:
нет аудиофайлов. Числа в каталоге — целевые параметры.

Unity 6000.6.0f1 установлен и открыт в исходном рабочем каталоге.
В новом worktree Editor не запускался. Play Mode, импорт WAV и Windows build
с новой музыкой не проверялись: WAV и новая runtime-реализация отсутствуют.
MIDI не прослушан в DAW; проверена только структура и записанные события.

MusicManager предложен документально; автоматический запуск, громкость,
crossfade и переключение боссовых фаз пока не реализованы. Отдельные
transition-аудиофайлы не требуются выбранным планом и не созданы.

Исходная рабочая ветка feature/expand-levels осталась на месте. Её лес,
расширенные уровни и прочие незамерженные изменения не включены в этот PR.
