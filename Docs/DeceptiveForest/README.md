# Обманчивый лес — уровень 2: Ложная тропа

Это второй уровень **внутри Deceptive Forest**, отдельная непрерывная сцена длиной
84 мировые единицы. Создан и сохранён Unity **6000.6.0f1** через Editor API.
Исходный Appi, PlayerController, PlayerDeath и PlayerSpriteAnimator переиспользованы.
Новые зависимости не добавлены. Проверки и ограничения: [Validation.md](Validation.md).
Полный список созданных и изменённых файлов: [ChangedFiles.md](ChangedFiles.md).

## Запуск

1. Открыть `Assets/_Trapple/Scenes/DeceptiveForest/DeceptiveForest_Level02.unity`
   либо **Trapple → Deceptive Forest → Open Level 2**.
2. Нажать Play и дать фокус Game View. Существующий обработчик Play Mode выбирает
   отдельный `Assets/_Trapple/Settings/DeceptiveForestPreview.asset` и затем
   восстанавливает прежний профиль.
3. Для самостоятельной игры: **Trapple → Deceptive Forest → Build Windows Preview**.
   Результат — `Builds/DeceptiveForest/Trapple.exe`, стартующий сразу с Level 2.

Сохранённая сцена готова к запуску; генерацию повторять не нужно.
`Create Level 2 (only if absent)` отказывается перезаписывать существующую сцену
и префабы. Старые Rebuild Hub / Tutorial для этого уровня не используются.

## Управление

| Действие | Клавиша |
| --- | --- |
| Движение | A / D или ← / → |
| Прыжок | Space |
| Подобрать палку рядом | E |
| Бросить в последнем направлении движения | F |
| Пауза / продолжить | Escape |
| Повторить после финиша | R или кнопка |
| Навигация в модальном окне | Tab / Shift+Tab, Enter; мышь |

E/F — локальные сериализованные поля ForestStick, глобальная схема ввода не менялась.
Полноценной анимации рук/броска в источниках нет: палка показывается рядом с Appi.
Уклонение не реализуется этой задачей.

## Маршрут

| Участок X | Содержание | Подсказка / безопасное действие |
| --- | --- | --- |
| −4…9 | Безопасная лесная опушка, точка старта (0, 0.65) | Движение и пробный прыжок |
| 9…18 | Ложная земля над шипами | Короткий тонкий край, дрожание при контакте; сразу отпрыгнуть |
| 18…32 | Четыре опоры на высотах 1.2, 2.4, 3.4, 2.0 | Вторая опора мигает тёплым цветом перед исчезновением |
| 32…46 | Палка около пня (36.5, 0.65), преграда X=41.5 | E подобрать; подойти и бросить F вправо |
| 46…49 | Яблоко-приманка на крышке скрытой ямы | Перепрыгнуть весь участок; яблоко не является финишем |
| 49…80 | Нестабильный шаг, падающее дерево и настоящая цель | Войти в предупреждающую область около X=60, отойти влево, дождаться падения, перепрыгнуть ствол |

Настоящая цель X=76 отмечена флагом. Её trigger срабатывает один раз,
останавливает Appi и открывает завершение с повтором и возвратом в Hub.
Падающее дерево опасно стволом во время движения; крона декоративная.
После падения ствол становится безопасной низкой опорой.

## Физика и параметры

Базовая скорость 6, ускорение 60, торможение 70, высота прыжка 2.4,
gravityScale 3, gravity Y=−9.81, CapsuleCollider2D 0.75×0.95.
Начальная вертикальная скорость ≈11.89, время прыжка на прежнюю высоту ≈0.81 с,
теоретический горизонтальный предел ≈4.85; с разгоном от остановки ≈4.55.
Восходящие переходы имеют подъём не более 1.2 и расстояния около 3.1–3.3.
Самый длинный плоский прыжок в проверенном маршруте — около 4.3.
Эти расчёты дополнены автоматическим прохождением на настоящей физике Unity.

| Объект | Настройка |
| --- | --- |
| FalseGround, Unstable step | Существующий FallingPlatform; задержка 0.7 с |
| Fading branch | Предупреждение 0.85 с; collider и спрайт выключаются одновременно |
| Hidden pit cover | Предупреждение 0.55 с, единственная основная ловушка приманки |
| Падающее дерево | Предупреждение 1.1 с; падение 0.85 с; поворот 90° вокруг основания |
| Палка | Радиус подбора 1.65; бросок (±11, 3); gravityScale 1.4 |
| Возврат палки | Через 4 с после любого броска, при Y&lt;−5 или удалении от старта более 18 |
| Смерть | Существующий PlayerDeath, автоматическая перезагрузка через 0.65 с |
| Камера | Orthographic size 6; горизонтальные границы −4…80 с учётом ширины кадра; Y=3.4 |

Декоративные объекты не имеют физических коллайдеров. Ground использует слой 6.
Палка повторно включает IgnoreCollision после броска, поскольку отключение
коллайдера на время удержания сбрасывает игнорируемые пары Unity.

## Архитектура и интеграция

- FallingPlatform и SpikeTrap используются без изменения их поведения.
- ForestDisappearingPlatform обслуживает и исчезающую ветвь, и крышку ямы.
- ForestFallingTree + ForestTreeTrigger отвечают только за дерево.
- ForestStick и ForestStickTarget реализуют одно локальное взаимодействие.
- ForestPlatformWarning добавляет только дрожание картинки падающей опоры.
- ForestCamera ограничивает слежение: TutorialCamera не имеет границ, а камера
  Hub умножает X игрока на 0.55, поэтому для этого длинного маршрута они не подходят.
- ForestUI использует существующий GameManager для паузы, перезапуска и переходов.
  Escape обрабатывается только GameManager. Лесной UI не является глобальной системой.
- GameManager.CompleteLevel — общий вход в Victory; прежний CompleteBossFight
  делегирует ему, сохраняя API босса. GameInterface скрывает IMGUI только в лесной сцене.
- ForestGoal не заменяет TutorialGoal: последний содержит специфичные Tutorial
  IMGUI-надписи, горячую клавишу и контракт награды Hub. Новой цели награда не назначена.

Сцена зарегистрирована в общем списке и отдельном тестовом профиле.
`HubConfiguration.asset`, разблокировки и `Trapple.HubPreview.v1` не изменяются.
Обычная карта миров **не запускает Level 2**: Level 1 и production-прогрессия леса
отсутствуют. Счётчик семечек отображается только при наличии существующего сервиса Hub;
при прямом старте без него скрыт. Постоянные награды, валюта и ключи PlayerPrefs не добавлены.
Level 3 не существует, поэтому кнопки перехода к нему нет.

## Графика и UI

Полный реестр 79 изображений: [AssetInventory.md](AssetInventory.md).
Происхождение двух производных и точные промпты: [ArtSources.md](ArtSources.md).
Фон, дальние силуэты с параллаксом, отдельные деревья, земля и передние растения
собраны отдельными SpriteRenderer. HubAmbience переиспользован для листвы и параллакса.
Рисованное окружение использует Bilinear, исходный пиксельный Appi и палка — Point.

UI Toolkit: `Assets/_Trapple/UI/DeceptiveForest/Forest.uxml`, `Forest.uss`,
`ForestPanelSettings.asset`. База 1600×900, масштабирование по обеим осям.
Панели сохраняют пропорции; надписи программные. Кнопки имеют hover, focus,
pressed и disabled состояния. HUD не принимает Space как Submit во время движения.
Панель смерти краткая и без кнопок, поскольку сохранён автоматический перезапуск.
Аудиоресурсов в проекте не найдено; уровень работает без звука.
