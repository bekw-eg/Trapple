# Анимации атак Orchard Warden

Ветка: `feature/guardian-attack-animation`. Продолжение первого босса из PR #33.

У ветвей появились плечевые шарниры: большой замах, ускорение к земле, отдача и восстановление. Корпус сжимается перед корнями, крона запаздывает и встряхивается при контакте. Выпуск каждой волны листьев сопровождается движением рук и кроны; сами листья вращаются и покачиваются.

Корни поднимаются из почвы и уходят обратно с закреплённым основанием. Их коллайдер растёт вместе с видимой частью. Вращение и растяжение спрайтов отделены от физического объекта. Для первого босса между завершением предупреждения и контактом есть 0,2 секунды на движение удара; подсветка и текст предупреждения сохраняются до контакта. Прежний Forest Guardian сохраняет нулевую задержку.

Пыль, камешки и веер листьев используют заранее выделенные 32 спрайта без коллайдеров. Отмена боя, оглушение, смерть и победа очищают эффекты и ожидающий удар. Пауза останавливает позу и частицы, включая кадр запроса паузы.

## Проверка

Unity **6000.6.0f1**. Prefab сохранён установленным редактором через `MeadowBossBuilder.Build`. Изменения идентификаторов объектов от повторной генерации сцен исключены: обе существующие сцены получают изменения через общий prefab OrchardWarden.

- PlayMode: **54 passed, 0 failed, 1 skipped** по последнему результату каждого уникального сценария двух прогонов. Это объединённый результат, а не один полный запуск. [Точные сценарии](TestResults.json).
- Итоговый отдельный прогон первого босса и анимаций: **16/16 passed**. Проверены подъём корней, рост коллайдера, плечевой замах, задержка урона, восстановление, покачивание листьев, остановка в паузе и отмена удара до контакта. Три настоящих физических уклонения, весь survival-отсчёт, смерть/повтор и переходы мира также прошли.
- Регрессии Forest Guardian, физики листьев/палок, прежней BossTest, HUD и экрана смерти прошли. Пропущен только старый opt-in тест responsive-снимков экрана смерти.
- EditMode: **30/30 passed**.
- Windows x64 Development: **Build Finished, Result: Success**, exit **0**. Локально: `Builds/Hub/Trapple.exe`.
- `git diff --check` прошёл.

Первый прогон выявил дополнительное изменение позы в LateUpdate кадра паузы. После явной проверки Time.timeScale повторный тест прошёл. Финальные проверки используют существующие сцены с обновлённым prefab.

GPU-запись содержит **126 игровых кадров**, по 42 для каждой атаки. GIF собраны из этих кадров, а не из макетов. В записи физика игрока отключена для обозрения атаки; уклонения проверены отдельным тестом с настоящими PlayerController и Physics2D.

## Изменённые файлы

- `Assets/_Trapple/Scripts/Bosses/ForestGuardianAnimation.cs` — позы, плечевые замахи, крона, отдача и восстановление.
- `Assets/_Trapple/Scripts/Bosses/ForestGuardianController.cs` — момент контакта, сигналы эффектов, отмена ожидающего удара.
- `Assets/_Trapple/Scripts/Bosses/ForestGuardianHazard.cs` — отдельная анимация спрайта, появление корня и покачивание листа.
- `Assets/_Trapple/Scripts/Bosses/GuardianAttackEffects.cs` и `.meta` — пул декоративных частиц.
- `Assets/_Trapple/Scripts/UI/MeadowBossHUD.cs` — предупреждение до контакта.
- `Assets/_Trapple/Editor/MeadowBossBuilder.cs` — авторинг плечевых шарниров и эффектов.
- `Assets/_Trapple/Prefabs/OrchardWarden/OrchardWarden.prefab` — обновлённый первый босс.
- `Assets/_Trapple/Tests/PlayMode/GuardianAttackAnimationTests.cs` и `.meta` — пять проверок поведения и opt-in запись.
- `Assets/_Trapple/Tests/PlayMode/OrchardVisualTests.cs` — общий метод GPU-захвата.
- `Docs/GuardianAttackPolish/` — этот отчёт, результаты, три GIF, таблица кадров и описание PR.

Сцены, исходные изображения, маршруты и ресурсы второго босса не перезаписывались в итоговом изменении.
