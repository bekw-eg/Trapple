# Разные атаки двух боссов

Ветка: `feature/guardian-varied-attacks`. Продолжение PR #34, исходный коммит `946ec13`.

| Босс | Набор атак |
| --- | --- |
| Orchard Warden, мир 1 | Корни под Аппи, удар ветвью, низкие листья, дождь ветвей, прыгающие яблоки — 5 паттернов |
| Forest Guardian, мир 2 | Корни под Аппи, удар ветвью, низкие листья, дождь ветвей, бегущая волна корней, веер золотых листьев — 6 паттернов |

Дождь состоит из **50 настоящих опасных ветвей за одну непрерванную атаку**, десяти залпов по пять. Во время замаха босс поднимает обе руки с большой ветвью, затем поддерживает дождь движениями рук. Каждый залп ориентируется на текущее положение Аппи. После появления отметки цель фиксируется: ветвь не подруливает за игроком. Между местами падения остаются проходы, отметки видны до приземления и располагаются на поверхности платформ. Предупреждение длится 0,75 секунды, затем ветвь падает с ускорением.

Первый босс стряхивает **шесть яблок**: они падают по дуге, отскакивают и катятся, создавая угрозы на разных высотах. Второй босс посылает **11 последовательных корней** через арену и **три веера по три листа** с разными вертикальными скоростями. Золотые листья отличаются от зелёной декоративной листвы. Крупные подсказки обеих арен называют текущую атаку.

В первом мире сохраняется бой на время, во втором — прежняя возможность наносить урон палками. Попадание во второго босса прерывает и очищает его дождь. Смерть, отмена боя и победа удаляют активные снаряды и зарезервированные падения. Пауза замораживает предупреждения, позы, падение и частицы. Пул из 32 физических снарядов и 20 отметок выделяется перед боем.

## Проверки

Unity **6000.6.0f1**. Prefab и Sprite сохранены установленным Unity Editor через `GuardianVarietyBuilder.Build`, без ручной генерации YAML. Повторный запуск сохраняет существующие GUID и плечевые шарниры. Сцены и маршруты не перегенерировались.

- **63 PlayMode passed, 0 failed, 2 skipped** по последнему результату каждого уникального теста трёх прогонов. Это объединённый результат; [точные сценарии и исходные XML-имена](TestResults.json).
- Первый расширенный прогон: 61 passed, 2 skipped. После улучшения отметок и добавления физических проверок: 25 passed, 1 skipped. После смены цвета веера: 2/2 passed с повторной GPU-записью.
- Два пропуска — прежние opt-in записи старых анимаций и responsive-экрана смерти; новая запись пяти атак выполнена.
- Проверено ровно 50 запланированных и выпущенных ветвей у **обоих** боссов, фиксация целей после отметки, отсутствие переполнения пула, остановка в паузе и удаление отложенных падений после смерти.
- Проверены настоящие отскоки/качение яблока и его столкновение с PlayerDeath, последовательное продвижение корней, три разных траектории веера и прерывание дождя уроном по Forest Guardian.
- Через обычные PlayerController/Physics2D проверены движение с прыжками под начальными залпами дождя, пересечение волны корней и прыжок через одно изолированное катящееся яблоко. Старые три атаки, полный 45-секундный отсчёт, повтор после смерти, завершение и переходы мира также прошли.
- Регрессии палок, летящих листьев, BossTest, HUD и экрана смерти прошли.
- **30/30 EditMode passed**.
- Финальная Windows x64 Development: **Build Finished, Result: Success**, exit **0**. Локально `Builds/Hub/Trapple.exe`.
- `git diff --check` прошёл.

Во время визуальной проверки тёмная текстура отметки была заменена на яркую, а зелёный веер — на золотистый для читаемости на фоне леса. Повторные проверки и снимки относятся к окончательным ресурсам.

Полные новые бои на физической клавиатуре, баланс сложности новым игроком, длинные маршруты от хаба и запуск экспортированного EXE вручную не проверялись. Автотест полного дождя проверяет количество и жизненный цикл с отключённой физикой игрока; это не утверждение о ручном прохождении всех 50 падений. Автоматические проверки оставшихся ошибок не выявили.
