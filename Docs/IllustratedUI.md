# Три экрана Trapple

Готовые панели uGUI: карта миров, мастерская и гардероб. Используются предоставленные иллюстрации, координаты `unity_hotspots.json`, Unity UI Button и TextMeshPro с запечённым кириллическим шрифтом Liberation Sans (OFL из TMP Essential Resources).

## Запуск

1. Открыть проект в Unity **6000.6.0f1**, дождаться импорта пакетов.
2. Открыть `Assets/_Trapple/Scenes/Menu/TrappleUI.unity` и нажать Play: сразу откроется карта миров поверх игрового хаба. `X` / Escape закрывают панель и возвращают управление герою в этой же сцене.
3. Обычный игровой путь также работает: `MainMenu` → PLAY → Hub. Подойти к мастерской, гардеробу или порталам и нажать **E**. `X` / Escape закрывают панели и возвращают управление герою.
4. Вкладки переключают панели без загрузки сцены. Кнопка меню в мастерской возвращает в существующее главное меню. Настройки хаба остаются доступны по Escape, когда панели закрыты.

Ничего вручную собирать в Inspector не требуется. Общий префаб: `Assets/_Trapple/UI/Illustrated/Prefabs/TrappleUI.prefab`. Его `TrappleUIManager.Initialize` принимает существующие сервисы и обработчики навигации; отдельная демонстрационная сцена использует `IllustratedUIBootstrap`.

## Повторная сборка

**Tools → Trapple → Build UI** импортирует PNG, читает hotspots, подготавливает фоновые варианты с очищенными демонстрационными значениями, собирает префаб и отдельную сцену, подключает их к существующему Hub. Повторный запуск заменяет созданный UI в хабе, сохраняя остальные объекты сцены. Предварительно сохраните открытые изменённые сцены при запросе Unity.

Исходные PNG лежат в `Assets/_Trapple/UI/Illustrated/Art`, производные фоны — в `Generated`. Полные вырезанные карточки не накладываются поверх исходного экрана. Разные пропорции трёх иллюстраций сохраняются через AspectRatioFitter и единое масштабирование координат. Пространство вокруг рамки прозрачно: за интерфейсом видна сама игра, камера и окружение продолжают работать. Деревянная рама и пергамент внутри панелей сохраняются. Динамические значения и интерактивные области используют ту же геометрию.

## Настройки и подключение игровой логики

Единственная конфигурация: `Assets/_Trapple/Settings/HubConfiguration.asset`.

- `upgrades[].costs`: три **положительные** цены. По умолчанию `-1`: покупка недоступна с сообщением. Ноль, отрицательная или отсутствующая цена никогда не дают бесплатное улучшение. Максимум — три уровня. Новый профиль начинает с нуля семечек; автоматическая награда обучения отключена до утверждения экономики.
- `percentPerLevel`: только отображаемый бонус. `IUpgradeApplier` — точка подключения будущей согласованной системы характеристик. UI не меняет физику игрока.
- `worlds[].levelScenes`: реальные пути сцен в Build Settings. Для поляны подключена существующая `Tutorial.unity`. У остальных миров пути пустые: доступный мир сообщает, что игровая сцена недоступна. BossTest не выдаётся за готовый лесной уровень.
- `plannedLevels`: обучение — один уровень; остальные миры — три. `requiredCompletedWorldId` связывает открытие следующего мира с завершением предыдущего. `completionRequiresBoss` включён у трёх будущих миров и выключен у обучения.
- `maximumStars`: по умолчанию ноль. Пока система звёзд отсутствует, карточки показывают число завершённых уровней, а не демонстрационные `0/30`. Условия выдачи звёзд UI не определяет.
- `cosmetics[].unlockRule`: Manual, WorldUnlocked или WorldCompleted; `worldId` задаёт нужный мир. Небазовые скины по умолчанию Manual. Базовый открыт сразу. Отдельно сохраняются выбранное превью и надетый скин; закрытый образ можно рассмотреть, но нельзя надеть.
- `cosmetics[].sprite`: существующий игровой спрайт; `previewSprite`: необязательное отдельное UI-превью. Если превью отсутствует, используется игровой спрайт, затем базовый; при полном отсутствии выводится сообщение. UI-картинки не назначаются игровыми анимациями. Скин влияет только на внешний вид.

Существующая точка доступа: `HubSceneFlowController.Instance.Progression`. Примеры интеграции будущих систем:

```csharp
var progress = HubSceneFlowController.Instance.Progression;
progress.AddSeeds(earnedAmount);                 // Источник и величину определяет игра.
progress.CompleteLevel("forest", levelIndex);   // Индексы от 0 до plannedLevels - 1.
progress.CompleteBoss("forest");                // После уровней; открывает следующий мир.
progress.SetStars("forest", earnedTotal);       // Только при настроенном maximumStars.
progress.GrantCosmetic("forest");               // Явное событие разблокировки.
```

Повторная запись завершения уровня/босса не выдаёт наград. Завершение существующего обучения отслеживается текущим `HubSceneFlowController`: прогресс сохраняется, лес открывается. Превью, статусы и баланс обновляются при событиях изменения и повторном открытии панели. Для внешнего открытия интерфейса в хабе вызывайте `HubUIController.Open`, чтобы сохранялось управление игроком и поведение Escape.

## Сохранение

Используется прежний адаптер `PreviewSaveService` и прежний ключ `Trapple.HubPreview.v1` — имя сохранено ради совместимости. Внутри JSON теперь версия **2**. Другого источника валюты, улучшений или скинов нет.

Данные версии 1 мигрируют с сохранением баланса, улучшений, экипировки и завершённого обучения. Старый демонстрационный баланс не обнуляется: отображается реальное сохранённое значение. Повреждённое/неподдерживаемое сохранение использует безопасные начальные значения; неизвестный/закрытый надетый скин заменяется доступным базовым. Название `Preview` сохранено для совместимости кода; это тот же локальный профиль, используемый текущим хабом.

## Проверки

EditMode: покупки, отсутствие цен, нехватка средств, максимум, миграция, загрузка, открытие миров с условием босса, конфигурируемые звёзды, выбор и экипировка скина.

PlayMode: существующая физика обучения и боссов, реальные сохранённые сцены, uGUI-вкладки и кнопки, возврат управления, повторное открытие, клики по закрытым/отсутствующим мирам и скинам, двойной клик покупки, raycast интерактивных областей.

Для проверки Windows-плеера выполните `Trapple/Hub/Build Windows Preview`, затем запустите development-сборку с аргументом `-trapple-ui-capture <absolute-output-directory>`. Диагностика сохраняет девять снимков трёх панелей при 1920×1080, 1600×900 и 1280×720, проверяет координаты кнопок, наличие игры под интерфейсом и восстановление управления после закрытия, восстанавливает сохранение и записывает `result.txt`. Этот режим запускается только явным аргументом и не работает в обычной игре.

## Ограничения контента

Исходники — плоские иллюстрации. Динамические области восстановлены из соседних участков того же фона; они не являются исходными многослойными/9-slice ресурсами. Встроенные статические подписи и декоративные миниатюры сохраняются. Игровые анимации новых скинов, сцены следующих миров, экономика, правила звёзд и секретные миры этой задачей не добавляются. Секретные миры показывают «Скоро».
