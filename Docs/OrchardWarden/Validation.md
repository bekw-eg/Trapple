## Что проверено

По последнему результату каждого уникального сценария: **72 PlayMode passed, 0 failed, 1 opt-in skipped**. Последний набор первого босса: **10/10 passed**, включая обычное движение/прыжок через все три атаки непосредственно на новой геометрии арены. Полный EditMode: **30/30 passed**.

- Реальный физический вход через TutorialGoal, однократное вступление и пропуск Enter.
- Во вступлении таймер стоит; пауза останавливает часы и атаки.
- Режим survivalOnly не принимает урон и не даёт победить повреждениями.
- Все **45 секунд реального scaled-отсчёта** доводят бой до Retreat и завершения. В этом тесте wall time ускорено через Time.timeScale, а столкновения игрока отключены; возможность уклонения проверяется отдельными физическими сценариями.
- Смерть вблизи нулевой границы не даёт победу. Прежний экран смерти и Respawn восстанавливают чекпоинт и исходный таймер.
- Два результата победы имеют рабочие pointer/raycast-кнопки. Continue из настоящего Tutorial загружает существующий Deceptive Forest.
- Победа записывается прежним progression-сервисом и восстанавливается новым экземпляром сервиса из того же сохранения. Тесты используют MemorySave и не засчитывают пользователю прохождение мира.
- Прежний Forest Guardian, полёт палок, повторное использование снарядов, размер HUD, обе победы леса и его чекпоинт проверены регрессионными тестами.
- На новой арене Orchard Warden Appi успешно избегает каждой атаки через настоящий PlayerController/Physics2D: прыжок с движением против корня, отступление от ветки, прыжок навстречу двум листьям. Телепортация применяется только для стартовой постановки отдельного теста, не во время уклонения.
- Проверены старая изолированная BossTest, карта, общие меню, пауза, экран смерти, таймер курса, камера и фоны длинных уровней.
- EditMode: **30/30 passed**.
- Windows x64 Development: **Build Finished, Result: Success**, exit 0. Локальный EXE — `Builds/Hub/Trapple.exe`, в Git не включается.
- `git diff --check`: успешно.

Сводка каждого сценария и точные числа PlayMode — [TestResults.json](TestResults.json). Результаты объединяются по последнему результату каждого уникального теста; это не заявление об одном полном запуске всей тестовой базы.
