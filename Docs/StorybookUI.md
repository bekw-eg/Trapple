# Внедрение Storybook UI в Trapple

Исправление композиции и контекстных подсказок: см. [UIComposition.md](UIComposition.md)
и [проверку со скриншотами](UIComposition/Validation.md). Общая нижняя доска
управления из первоначального внедрения заменена.

Обновление привязок Forest: см. `Docs/ForestPortalFix.md`. Forest теперь открыт
и связан с существующей сценой; ограничения карты ниже описывают состояние
первоначального внедрения UI.

Ветка: `feature/storybook-ui`. Основа — текущая ветка спринта Appi
(`f179e5a`, PR #24), содержащая актуальный `main` на момент начала работы.

## Существующая архитектура

В проекте шесть сцен: MainMenu, Hub, Tutorial, BossTest, TrappleUI и
DeceptiveForest_Level02. Главное меню, общая пауза и интерфейс босса ранее
рисовались через IMGUI. Лобби использовало HubUIController (UI Toolkit),
TrappleUIManager (Canvas/TMP) и отдельный WorkshopUIController с анимацией входа.
Лес имел собственный ForestUI. TutorialGoal выводил IMGUI-подсказку и завершение.

Обновление использует эти контроллеры и сервисы:

- GameManager: запуск игры, пауза, продолжение, повтор и смена сцены.
- HubUIController: открытие окон, блокировка и восстановление управления.
- HubSceneFlowController: переходы и доступ к единому прогрессу.
- PreviewProgressionService / UpgradeService: сохранения, цены, покупки, образы.
- WorkshopTransitionController: существующий вход через дверь, камера, iris,
  возвращение в лобби и демонстрация улучшений.

Новый GameInterface — Canvas-представление существующего GameManager. Его
prefab загружается из Resources при запуске любой сцены. В лобби остаются
движение Appi, взаимодействие через E и прежние переходы мастерской.

## Ассеты и prefab

Десять пользовательских PNG сохранены в `Assets/_Trapple/Art/SourceSheets`.
67 подготовленных элементов организованы в
`Assets/_Trapple/UI/Storybook/{Buttons,Icons,Panels,WorldMap,Workshop,Wardrobe,HUD,Settings,Fonts,Prefabs}`.
`slices.json` связывает элементы с исходными листами и координатами.
`Tools/prepare_storybook_ui.py` повторяет подготовку, не изменяя исходные листы.

Созданы PrimaryButton, SecondaryButton, SmallButton, IconButton, WorldButton,
LevelButton, UpgradeButton, WardrobeSlot, UIWindow и UISlider. Окна и подходящие
поверхности используют 9-slice; кнопки с нарисованными надписями сохраняют
пропорции и не получают второй текст. Пустые кнопки используются для динамических
подписей и состояний. Анимации кнопок работают на unscaled time, длительность
0,11 секунды. Поддерживаются hover, pressed, keyboard focus, выбранное и
неактивное состояния.

Использован оригинальный ThaleahFat.ttf автора Tiny Worlds / Rick Hoppmann:
[источник и лицензия](https://tinyworlds.itch.io/free-pixel-font-thaleah).
В исходном проекте этого TTF не было. Установлены оригинальный файл и TMP Font
Asset; атрибуция находится рядом со шрифтом. Надписи нового UI — английские,
как на концепт-листах: оригинальный Thaleah не содержит кириллицу. Строки
конфигурации и сохранения остаются прежними.

## Сцены и подключённые действия

Файлы сцен Hub и TrappleUI обновлены через Unity Editor API. MainMenu, Tutorial,
BossTest и DeceptiveForest_Level02 получают общий UI через GameManager без
перестройки геометрии сцен. Общий prefab:
`Assets/_Trapple/Resources/Storybook/GameInterface.prefab`.

| Экран | Действия |
| --- | --- |
| Главное меню | PLAY → существующее лобби; SETTINGS; EXIT (останавливает Play Mode в редакторе) |
| Лобби | WORLD MAP, WORKSHOP, WARDROBE, SETTINGS; E у объектов; BACK/CLOSE возвращают управление |
| Карта | Выбор мира, реальные уровни из HubConfiguration, locked/complete/selected, PLAY, BACK |
| Мастерская | SPEED/AGILITY/JUMP, текущие уровни и проценты, цена, UPGRADE/MAX, EXIT; прежняя живая демонстрация |
| Гардероб | Реальные образы конфигурации, выбор, locked/equipped, EQUIP, BACK/CLOSE |
| HUD | Существующие семечки при наличии сервиса прогресса; PAUSE; краткие подсказки движения; E/F по ситуации |
| Пауза | CONTINUE, SETTINGS, RESTART LEVEL, LOBBY, MAIN MENU |
| Завершение | LEVEL COMPLETE, RETRY, NEXT LEVEL при наличии следующей сцены, LOBBY |
| Настройки | MASTER VOLUME, сохранение прежнего ключа Trapple.MasterVolume, BACK |

Настройки из паузы сохраняют остановленное время. Первый ESC закрывает настройки,
следующий закрывает паузу. Навигация uGUI включается для открытых окон; во время
управления персонажем игровой Space не отправляет UI Submit.

## Ограничения существующих игровых данных

- В HubConfiguration цены улучшений равны -1. Покупка в обычном запуске
  недоступна, пока разработчики не зададут цены; баланс и начальные семечки не
  менялись. Покупки проверяются на временных тестовых ценах с восстановлением
  данных после теста.
- В карте реально назначен только Tutorial для Apple Meadow. У Forest,
  Factory и Lava `levelScenes` пусты. Существующая отдельная сцена Forest Level02
  получает новый HUD/паузу, но карта не придумывает её назначение в прогрессе.
- Правила звёзд отсутствуют (`maximumStars = 0`): новые награды и оценка не
  добавлены. NEXT LEVEL неактивна, если следующая зарегистрированная сцена
  недоступна.
- Улучшения в текущей архитектуре сохраняются и показываются в демонстрации;
  их применение к физике платформера остаётся прежним. Физика, прыжок, бег,
  спринт, ловушки и автоматическое возрождение не изменялись.
- У гардероба остаются только исходные образы и исходные условия открытия.
- В коде нет отдельных каналов музыки/SFX или вибрации: показана только реально
  поддерживаемая общая громкость.

Для динамических подписей используются пустые поверхности из листа 10. На
листах 4 и 6 есть нарисованные примеры уровней/стоимости/счётчиков — они не
используются как реальные значения. Несколько соседних кнопок паузы на листе 7
соприкасаются: для них выбраны пустые новые кнопки с Thaleah.

## Проверка в Unity

1. Открыть проект в Unity **6000.6.0f1**, дождаться импорта и компиляции.
2. Открыть MainMenu и включить Play. Проверить PLAY → Hub, настройки и EXIT.
3. В Hub проверить перемещение/прыжок/Left Shift, подход к мастерской и E,
   вход/выход через дверь, карту и гардероб. Закрыть окна мышью и ESC.
4. Через карту запустить Apple Meadow. Проверить PAUSE → SETTINGS → ESC →
   CONTINUE, RESTART LEVEL, LOBBY и MAIN MENU.
5. Дойти до настоящего яблока: проверить завершение и RETRY/LOBBY. Смерть
   по-прежнему вызывает автоматический повтор.
6. Открыть Forest Level02 напрямую и проверить E/F у палки и общую паузу.
7. В Game View проверить 1920×1080, 1600×900, 1366×768 и 2560×1440.
8. Проверить стрелки/Enter в меню; Space и стрелки во время игры должны
   управлять персонажем без нажатия HUD-кнопок.
9. Изменить громкость, закрыть окно и повторно запустить игру.

Готовые prefab и сцены уже сохранены. Для повторной сборки после изменения
ассетов: `Tools → Trapple → Build Storybook UI`. Сборщик меняет только UI и
сохраняет существующие ссылки на игровые системы. Полный перечень файлов —
`Docs/StorybookUIFiles.txt`.

- `git diff --check` без ошибок.
- Финальная Windows development сборка успешно собрана в
  `Temp/StorybookPlayer/Trapple.exe` (каталог исключён из Git).

Сводные снимки находятся в `Docs/Images/StorybookUI`, перечень проверок — в

Живые игровые уровни, автоматическое возрождение и исходные сохранения

PlayerPrefs; изменения цен и выдача образов используются только внутри тестов.
