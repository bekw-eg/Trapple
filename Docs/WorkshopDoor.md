# Покадровая дверь мастерской — 23 октября 2026

Подключён предоставленный лист `Изображение ChatGPT 23 окт. 2026 г., 00_01_08.png`. Оригинал находится в `Assets/_Trapple/Art/Workshop/Source/WorkshopDoor8Frames.png` и сохранён без изменения пикселей.

## Поведение

- Открытие: верхняя строка 1, 2, 3, 4, затем нижняя 5, 6, 7, 8.
- Закрытие: 8, 7, 6, 5, 4, 3, 2, 1.
- Каждый кадр получает отдельную выдержку; промежуточные кадры не пропускаются из-за easing индекса.
- Закрытый первый кадр остаётся видимым между посещениями.
- По умолчанию длительность — 0,64 с, настраивается у WorkshopDoorAnimator. Используется время, независимое от timeScale.
- Сброс, отключение или запуск обратной последовательности отменяет прежнюю последовательность; она не продолжает открывать дверь позже.

Существующая кат-сцена сама открывает дверь перед проходом персонажа и закрывает после него. При выходе используется тот же компонент с обратным воспроизведением. Игровая физика, экономика и демонстрации улучшений не менялись.

## Импорт и установка

Лист содержит восемь полных изображений домика, поэтому анимируется SpriteRenderer домика целиком. Прежний статичный SpriteRenderer у станции Workshop отключён. Временный прямоугольный проём заменён настоящими кадрами. Существующий тёплый свет сохранён.

Из исходного листа размером 1983×793 импортируются восемь спрайтов WorkshopDoor01…WorkshopDoor08. Окна одинаковые: 488×376, с шагом 496 по X и 384 по Y. Отступ 4 пикселя исключает линии разделения; нижнее поле листа не является частью последнего ряда. Одинаковый pivot удерживает общее положение домика.

Вокруг домика в исходнике есть тёмная полупрозрачная подложка. Материал `WorkshopDoor.mat` убирает её во время отрисовки через параметры Alpha Floor и Solid Alpha. Сам PNG не ретушируется.

Команда **Tools → Trapple → Build 2D Workshop** теперь импортирует эти кадры и подключает их к префабу и обеим сценам. Повторная сборка проверена. Editor entry point `Trapple.Editor.WorkshopDoorAssets.BuildAndCapture` выполняет две сборки и отрисовывает все восемь кадров через настоящую камеру Unity в `Builds/WorkshopDoor/Frames/`.

## Ограничения

Дверь и домик нарисованы одним слоем. Небольшие различия дыма и деталей домика между исходными кадрами сохранены. Другие платформы и ручной прогон физическими клавишами в видимом окне не проверялись.
